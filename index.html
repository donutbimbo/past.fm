Connect to Last.fm

past.fm reads your scrobbles straight from Last.fm. It needs your username and a free API key. Both stay in this browser on this device.

  1. Open last.fm/api/account/create while logged in.
  2. Fill in any app name, like "past.fm". Leave the callback empty.
  3. Copy the API key (not the shared secret) and paste it below.
